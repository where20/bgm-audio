既不被 `music.json` 引用，也不被 `index.html` 引用，是纯孤儿文件。

## 为什么在这里而不是删掉

**内容唯一，不可再生。** 这些文件的创作稿比 `lyrics/*.lrc` 更完整 —— 播放器用的 `.lrc`
受 600 字符上限约束，被精简过；根目录的 `.txt` 是未经裁剪的完整创作稿。

以 `lyrics_再熬一天就是国庆假期_20260930.txt` 为例：它比 `lyrics/再熬一天就是国庆假期_20260930.lrc`
多出 27 行独有内容，其中包含被裁掉的真实歌词：

```
我抬手 关掉了日程表
上面全标着 三亚 和 拉萨
```

`走啊汤恩伯` 是唯一例外 —— 19 行歌词与 `.lrc` 完全一致，属纯冗余。

5 个 mp3（`养龙虾` / `被正式确诊` / `邪修外耗歌` / `酸黄瓜` / `全民进入纯日子时代`）
是已下架历史歌的音频，`music/` 下无副本。

## 清理规则

- **不要往这里 cp 新产物**。新歌一律落 `hot-meme-music/music_output/` 与
  `hot-meme-music/generated-images/`，再经 `update_github_pages.py` 发布到 `music/` 与 `images/`。
- 仓内有 `.nojekyll`，Pages 会发布所有子目录，因此本目录**线上可访问**
  （`https://music.220616.xyz/archive/...`），旧根目录直链已 404。
- 若某天确认某首歌永不再上架、且其完整歌词已回灌进 `.lrc`，可再从本目录删除。
